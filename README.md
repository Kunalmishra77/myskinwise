# MySkinWise Marketing Site

Marketing site for [myskinwise.com](https://myskinwise.com), built with Next.js (App Router), TypeScript, and Tailwind CSS.

> This README is a placeholder scaffolded in Task 1 of the build plan. A full version (setup guide, env vars, asset-swap instructions) is written in a later task once the app is complete.

## Stack

- Next.js (App Router) + TypeScript (strict mode)
- Tailwind CSS v4
- Vitest + Testing Library (unit/component tests)
- Playwright + axe-core (end-to-end + accessibility tests)

## Scripts

```bash
npm run dev         # start the dev server
npm run build        # production build
npm run start        # run the production build
npm run lint          # ESLint
npm run test           # run unit tests once (Vitest)
npm run test:watch      # run unit tests in watch mode
npm run e2e               # run Playwright end-to-end tests
```

## Environment variables

None are required to run the site locally yet. See `.env.example`.
